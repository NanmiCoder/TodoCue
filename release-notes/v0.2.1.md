# TodoCue 0.2.1

修复任务表单中的草稿串用、文本拖选和保存问题。

- **新任务内容保持独立。** 修复新建任务继承其他任务备注、切换表单显示旧内容的问题。创建草稿与各任务的编辑草稿分别保留，填写新标题后展开详情不会带入旧备注或附件。
- **备注可以正常拖选。** 修复拖拽选择标题或备注时整个窗口移动的问题。需要移动面板时，拖动顶部空白区域即可。
- **版本冲突可以恢复。** 任务在别处被修改时，保留当前输入并提供重新载入最新任务的入口，避免始终拿旧版本反复保存失败。
- **草稿与异步操作更可靠。** 修复清空草稿后旧内容重新出现、已保存草稿再次恢复，以及晚到的保存或附件结果影响其他表单的问题。仅查看、未修改的任务重新编辑时会读取最新内容。
- **修复附件和属性操作。** 属性清除按钮独立响应；多个拖入文件按批次校验数量与大小；首个附件导入失败也会显示错误；导入期间暂停重复导入和保存。
- **重复设置更清楚。** 重复任务统一使用重复设置中的开始日期、时间和提醒，并恢复首次任务的附件说明。补齐新表单相关英文文案。

新增 12 个回归测试，覆盖草稿隔离、连续创建、保存竞态、版本冲突、附件限制和真实原生输入框的鼠标拖选。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App 即可；原有任务数据保留在 `~/.todocue`。
