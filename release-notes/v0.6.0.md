# TodoCue v0.6.0

TodoCue 的正式桌面发行改为共享 React / Tauri 客户端，同时提供 macOS 与 Windows 安装包。任务引擎、SQLite、REST API、CLI 和 MCP 继续使用原实现，数据目录与 v0.5.x 兼容。

## 下载与安装

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。将 TodoCue.app 拖入 Applications，退出旧版后打开；内置 Node、SQLite、通知辅助程序和 Skill，自动建立当前用户后台与 CLI，无需额外安装 Node。两个 DMG 均经 Developer ID 签名、Apple 公证及 stapling 验证。
- Windows：x64 选择 `Windows-x64-setup.exe`（Windows 10/11），ARM64 选择 `Windows-arm64-setup.exe`（Windows 11）。当前用户安装，内置对应架构的 Node、SQLite、通知辅助程序及离线 WebView2。Windows 安装包未做 Authenticode 签名，系统可能显示未知发布者；请只从本仓库 Release 下载，并核对 SHA256SUMS。
- 试用过 Preview 的 Windows 用户先卸载 Preview，保留数据后再安装正式版，避免两个安装目录同时注册系统集成。

## 本版变化

- 今日、即将到来、全部任务、表单、详情、月/周日历、历史、附件与周期提醒使用同一套共享界面；保留 Dial 配色、布局、输入草稿和动效。
- 修复刘海展开后焦点、粘贴、回车与提交期间继续输入的问题；网络失败保留草稿，连续回车防重复创建。
- 修复 Mac 直接从 Finder/Dock 打开持续离线；安装包自动启动后台，显式选定的数据目录会保留到下次启动。后台启动失败提供错误信息。
- Mac CLI 绑定所选数据目录，更新保留自定义后台端口。Windows 更新失败保留恢复记录与数据，支持重试；退出 UI 不停止后台提醒。
- 发布前运行完整回归，并在 Mac Apple Silicon/Intel、Windows x64/ARM64 上构建和检查真实安装产物；四个安装包及校验和全部齐全才公开 Release。

## 升级、边界与回退

默认数据仍在 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），支持 `--home` / `TODOCUE_HOME`；卸载或更换 App 保留数据库与附件。开发和验证继续使用隔离目录。旧的 SwiftUI 客户端运行时，通用版会提示先退出，避免同时操作同一份数据。原生偏好与 Apple 同步关联记录保持原样。

本版尚不提供旧 SwiftUI 客户端的 Apple 日历/提醒事项同步、硬件刘海安全区适配及全部偏好自动导入。依赖这些功能的用户可继续使用 v0.5.3；退出通用版后装回 v0.5.3 并使用同一数据目录即可恢复旧客户端。没有改变任务 API 或数据库格式。

Windows GUI、多屏/DPI/休眠/通知点击，以及 Mac 真实鼠标/输入法候选和逐帧动效的完整硬件验收仍保留。CI 安装与自动回归不等同于全部 SwiftUI 效果已完全复刻。详细证据与未验收项目见 [迁移交接](https://github.com/NanmiCoder/TodoCue/blob/main/docs/desktop-handoff.md)。
