# TodoCue 0.5.3

刘海上的提醒现在会一直留到你处理它，不再几秒后自己消失。

- **提醒落下后常驻。** 周期提醒和任务提醒以整卡落下约 6 秒，随后在原地收成一行，一直留在刘海下，直到你点「完成」、「10 分钟后」或「今天暂停」，或它已在别处被处理。以前它 9 秒后就会收起。
- **多条提醒叠在一起。** 最多显示 3 行，任务提醒在上、周期提醒在下，各自按到达先后排列，位置不会因为别的提醒到来或离开而变动；第 4 件起折叠为「还有 N 件」，点开就是快览，顶部新增「待你回应」分区。
- **同一条规则只占一行。** 你还没回应，它又到了下一个时间点，原来那一行会加上 ×2、×3，不会越堆越多。
- **先收起，不会丢。** 点 × 把整个堆叠收进刘海左翼，翼标显示还有几件在等你，每隔几分钟轻轻闪一下；有新提醒时会重新展开。收起不算处理，任务和规则都不受影响。
- **更不容易点错。** 鼠标正停在堆叠上时，新提醒先在标题栏记一个「+N」，等你移开再入列；点别处、切换桌面、打开面板都不会把提醒收走。
- **按时段进退。** 周期规则离开它的生效时段（比如午休或下班后），对应的行会先退场，回到时段内再落下一次；重启 App 或重新连接后，仍在等你回应的提醒会自动回来。
- **面板轮廓更清楚。** 在白色页面上，面板的外缘补上了描边和窗口阴影，分得清边界。

只在 App 运行且当前屏幕有刘海（或开启了虚拟刘海）时展示；全屏应用前台并开启「全屏时不显示」时，只在刘海翼标上显示数量，退出全屏后恢复。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App。本版本不改变数据库结构，原有任务数据保留在 `~/.todocue`。
