## 原生对照与体验修正

以 `apps/macos/Sources/TodoCue` 的 HeaderView、NextCard、TaskRowView、QuickAddView、TaskFormView、TaskDetailView、NotchView，以及实际运行的 SwiftUI 面板作为基准。离屏截图出现 NSGlass/SF Symbols 占位时不用作视觉真值。

共享尺寸来自 `src/tokens.ts`：340 默认宽、14 外边距、42 外壳圆角、28 卡片圆角、10 间距、60 数字、84 表盘、185×24 刘海基体及 44 宽摘要翼。字体继续分发 Michroma 与 OFL。SVG 按原轮廓校准，避免用 Unicode 字符替代系统图标。

已调整头部层级、数字与日期位置、下一步高度、元数据、16 宽拖动柄、26 点击区/18 圆圈、左侧 42 快速添加圆盘、卡片与列表共同滚动、固定底部输入。页面重叠交替而不分摊高度；退出页面停止接收输入。表单属性使用独立浮层、图形日期选择、项目和耗时预设。日历随短窗口折叠为所选周，保留议程空间。

弹簧 response/damping 转为物理参数；刘海宿主用 0.32/0.86 校准窗口边界变化，避免只有内容淡入而窗口突然跳大。减少动态效果时跳过这段运动。新提醒完整展示约 6 秒再收成常驻行，移屏驻留为 1.5 秒；周期提醒只有实际可见的卡片才 claim/receipt，未显示的 offer 留给系统渠道。

本轮按真实 SwiftUI 首页、表单、详情、日历窗口继续校准。标题/备注自动增长，属性显示实际值和独立清除操作，附件采用原版缩略图列数并支持焦点约束预览。日历区分待办计划、历史和截止标记，区域周起始统一用于日历/日期弹层。数字改为按位滚动，表盘面与指针共用连续进度，完成等待 420ms；减少动效实时切换且保留编辑会话。Ego Lite 全页面布局矩阵已通过；字体抗锯齿、系统玻璃、原生 Quick Look 差异与逐帧采样不足仍单独记录，不承诺逐像素一致。

另验证拖动排序与撤销、今日已完成展开后重新打开。本轮 Ego Lite 448 条测量覆盖 14 个页面状态的语言/主题/动效/宽度矩阵，160 条补充附件/表单矩阵，24 条覆盖最小 360 高度，均实际确认媒体匹配、无横向溢出、底部操作可见；不替代全部原生视觉验收。原生窗口从 340 调整到 400 后，重启保留 400 宽度；Mac 内侧边缘调整宽度、底边 680→620 调整高度，以及双击恢复 340×680 均通过实际操作。Tao 的 macOS 缩放拖动尚未实现，因此此平台使用宿主尺寸桥接，Windows 保留 Tauri 原生路径。

### 截图反馈与刘海交互

macOS 虚拟刘海改为位于屏幕顶部，使用菜单栏高度，窗口层级为 `NSStatusWindowLevel + 1`；Windows 仍按工作区顶部定位。原生截图确认收起窗口为 273×30 逻辑像素，布局测试覆盖平台差异及顶部/侧边任务栏；真实硬件刘海、安全区及多屏行为仍待验收。

刘海快速输入改为 36 高的圆角胶囊，焦点描边由容器绘制，移除输入元素的橙色矩形 outline；面板快速输入、搜索和表单正文也移除不符合原生对照的矩形 outline。字体、图标、尺寸与动效仍需逐页校准，不能仅凭这次调整宣称 UI 已与 SwiftUI 一致。

macOS 安装 AppKit 本地与全局鼠标监听；点击其他窗口时收起快览并保留草稿。原交接机器曾用另一应用窗口的实际坐标点击验证收起，重新展开后草稿仍在；提醒堆叠不因外部点击被清除。本轮物理鼠标结果仍待验证。避免把原生失焦直接等同于外部点击，以减少输入法候选窗口或焦点变化导致的误收起。

本轮原生 Preview 已通过英文输入、中文粘贴、⌘A 替换、双回车去重、加号聚焦和 Esc 两阶段；退出控件立即从 AX 树消失后，连续三轮快速展开/立即粘贴创建通过，API 核对各标题只有一条任务。保存中同名重输使用 onInput 记录代次，浏览器延迟真实创建响应后确认草稿保留；收起期间返回也不会重新抢焦点。IME 确认键同时保护 isComposing 和 WebKit 229。

最新 `fdb8ce3` 同时激活宿主窗口/WebView first responder，箭头提交在禁用按钮前同步交回输入。最终原生包通过刘海和主面板箭头提交后直接继续输入；分别暂停隔离运行时，在真实响应前不重新点击输入直接 Cmd+A/粘贴下一条，恢复后完整草稿与焦点均保留。原生延迟保存时 Tab 转向查看全部，响应返回后保持按钮焦点。隔离运行时超时后重试仍只创建一条，REST 核对通过。控件点击通过 AX action 完成，不能据此关闭物理鼠标验收项。

原生坐标工具仍报 `noWindowsAvailable`，本轮没有可靠的物理外部鼠标证据；真实鼠标外部点击、拖选、输入法候选窗口及多屏仍保留验收项。所有临时事件诊断已清理。刘海的进度文字、恒定点径、按钮圆盘、行尾操作共用时间位置、紧凑行/输入/空状态和减少动态效果已按实际 SwiftUI 画面校准；完整视觉/动效验收未完成。

### 审查发现的八项修复

| 失败场景 | 修复与证据 |
| --- | --- |
| 临时 `TODOCUE_HOME` 启动后，安装器无法停止自定义目录的服务 | 当前用户目录 `%LOCALAPPDATA%\\TodoCue\\homes` 持久化安装路径与数据目录关联；无原 shell 环境的升级/卸载模拟覆盖两个自定义目录，并保留其他安装的服务 |
| 四条周期提醒同时领取，第四条无法展示且失去系统投递 | 在第一次异步操作前预留三行容量，直到回执完成；真实引擎验证第四条保持未领取，并在 offer 超时后通过系统渠道投递；领取期间任务到达不挤走未回执行 |
| 保存过程中移除上传附件，保存返回后附件复现 | 以提交顺序和原附件 ID 对应新增附件，把期间移除的上传转为下一次写入的移除 ID；覆盖新建、编辑、同名同内容文件，浏览器实际延迟保存后的第二次写入确认附件为空 |
| 重新打开两条已完成任务，旧查询响应又恢复已完成行 | 事件、重连与操作触发的历史刷新共用请求代次；浏览器保留两个含 B 的旧响应，先重新打开 A/B 再放行响应，界面为空且后台两条任务均为 todo |
| 日历拖到同日但晚于截止时间，跳过确认 | 在任务时区中计算实际改期瞬间，确认与写入使用相同时间；覆盖 UTC、上海、纽约夏令时；浏览器实际拖动 18:00 任务到次日 17:00 截止日，确认前数据不变，确认后保留截止时间 |
| 改变服务端口后仍由旧宿主继续运行 | 更新注册和清单前停止已注册任务，等待计划任务状态及宿主互斥释放；模拟异步退出验证旧清单不提前覆盖、新宿主采用新端口，停止失败不替换、注册失败恢复旧服务 |
| 自定义目录通知冷启动进入默认目录 | 通知 URI 携带已登记目录的短标识，宿主验证归属后选择目录；每个目录独立处理热启动，避免进入别的数据或丢弃草稿；未知标识不回落到默认目录，token 和原始目录路径不放入 URI |
| 产品卸载留下不可用的 CLI 与 PATH | 产品卸载按运行时指针归属清理 CLI、指针、受管理 PATH、UI 登录启动项和服务关联；保留数据库、备份以及其他安装的集成；单独 `service uninstall` 保留 CLI |

安装器同时区分普通卸载与更新/维护替换；连续两次停止保留恢复标记，更新后恢复原本运行的服务。分支已按当前 Tauri CLI 2.12.2 的 [NSIS 模板源码](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.12.2/crates/tauri-bundler/src/bundle/windows/nsis/installer.nsi)核对；本轮已在 Windows 两种架构实际执行安装、重装和卸载，验证服务恢复及数据库保留。

复测还修复了开发代理未转发 DELETE 请求体长度的问题；真实 Vite→HTTP→运行时测试验证任务与附件删除均收到版本参数。Windows 登录启动命令为可执行文件与自定义目录保留引号，覆盖含空格和末尾反斜杠路径。

本轮完整 Windows 构建发现并修复 NSIS 不打包 workspace junction，以及搬迁入口改变 runtimeRoot 的问题：使用普通目录转发到原模块路径，并验证删除原 staging 后仍能搬迁导入。数值 SID 权限字符串加 `*`，升级健康检查采用限时轮询（不主动启动服务）。真正安装后的 Node/SQLite、CLI/MCP 和计划任务均通过；通知助手已原生构建，但通知点击仍未验证。
