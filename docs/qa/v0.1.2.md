# TodoCue 0.1.2 验收

## 功能范围

- 原生任务拖拽排序、跨项目／日期移动、撤销与自动排序恢复。
- English／简体中文设置，立即生效并保存语言选择；默认跟随系统，其他语言回退英文。
- Agent 优先的双语 README，默认英文；两套高分辨率原生截图。

## 本地验证

- 完整 `npm run check:macos` 通过：79 项运行时测试、17 项发布脚本测试、真实 CLI／MCP／HTTP／SSE 冒烟，以及 71 项 Swift 测试。
- 英文和中文模式分别执行 Swift 测试，均通过。覆盖语言回退、选择持久化、插值不改用户内容、翻译占位符一致性及日期显示与存储分离。
- 新增截图用例仅显式运行：8 张 840 × 1360 PNG，标准测试中跳过。原生截图逐张检查了语言、文字清晰度、图片附件与鼠标缺席。
- 独立原生预览验证中文 → English → 中文即时切换，英文列表、设置、表单布局，以及重新启动后保留 English。中英文混合任务标题、备注保持原文。
- 拖动交互的原生验收与数据规则见 [拖拽设计](../design/drag-and-drop.md)。

## 数据隔离

测试使用内存数据库或全新的临时 TODOCUE_HOME。截图脚本分别创建英文、中文数据库，以 MemoryNotifier 代替系统提醒；捕获时排除其他窗口和鼠标叠层。真实应用及现有任务数据未修改。

## 发布门禁

本地检查完成后，主分支质量检查通过才推送版本标签。正式安装包由 Release macOS 工作流构建，要求 Apple Silicon 和 Intel 均通过测试、Developer ID 签名以及 App／DMG Apple 公证，再发布完整产物。
