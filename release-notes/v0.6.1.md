# TodoCue v0.6.1

v0.6.0 之后的修复与体验对齐版本：补回通用版缺失的退出入口，并把面板、刘海和宿主行为进一步向原 SwiftUI 版靠拢。任务引擎、REST API、CLI、MCP 和数据库格式没有变化，数据目录与 v0.6.0 兼容。

## 下载与安装

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。将 TodoCue.app 拖入 Applications，退出旧版后打开。两个 DMG 均经 Developer ID 签名、Apple 公证及 stapling 验证。
- Windows：x64 选择 `Windows-x64-setup.exe`（Windows 10/11），ARM64 选择 `Windows-arm64-setup.exe`（Windows 11）。Windows 安装包未做 Authenticode 签名，系统可能显示未知发布者；请只从本仓库 Release 下载，并核对 SHA256SUMS。
- 从 v0.6.0 升级：直接用新安装包覆盖安装，数据保留。

## 本版变化

- **补回退出入口**：面板「⋯」菜单底部新增「退出 TodoCue」；macOS 增加应用菜单与 ⌘Q，Windows 支持 Ctrl+Q。此前通用版只能从托盘菜单退出，而带硬件刘海的 MacBook 上托盘图标可能被刘海挡住，导致无法退出。退出只关闭桌面 App，后台提醒服务继续运行。
- 刘海：任务右键菜单、点击任务进入编辑/删除模式、Toast 吸顶、关闭菜单后不再残留固定状态，周期提醒在堆叠回落期不再丢失。
- 面板：入场淡入淡出、卡片内点击不抢键盘焦点、全屏应用下保持安静。
- 托盘：菜单随任务状态动态更新，修复转义、刷新与双击问题。
- 快捷键与撤销：⌘Z/Ctrl+Z 读取最新状态，删除确认容忍任务已被删除，菜单命令写入最新版本，撤销与错误提示统一走同一个 Toast。
- 宿主：新增打开数据目录、附件另存为、导出 JSON 到下载目录并提示；修复 macOS 全屏与多 Space、指针单位、面板淡入淡出竞态、导出异步、文件名清理与子进程回收。

## 升级、边界与回退

默认数据仍在 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），支持 `--home` / `TODOCUE_HOME`。旧的 SwiftUI 客户端运行时，通用版会提示先退出，避免同时操作同一份数据。

本版仍不提供旧 SwiftUI 客户端的 Apple 日历/提醒事项同步、硬件刘海安全区适配及全部偏好自动导入。依赖这些功能的用户可继续使用 v0.5.3，使用同一数据目录即可恢复旧客户端。

新增的退出菜单与 ⌘Q 已通过单元测试和构建检查，但尚未在真机上逐项点击验证；Windows 的 Ctrl+Q 与 GUI、多屏/DPI/休眠/通知点击等硬件验收仍保留，详见 [迁移交接](https://github.com/NanmiCoder/TodoCue/blob/main/docs/desktop-handoff.md)。
