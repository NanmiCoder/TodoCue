# TodoCue · 一眼知道下一步

2026-09-07。SwiftUI + AppKit 原生界面重构，面向 macOS 26，保留 macOS 14+ 运行兼容。

随后根据两位独立审稿人的意见，继续完成了列表密度、语义换行、表单对齐、操作提示与深色层级改进。最新状态与实拍对比见[审稿后改进记录](audit-refinements.md)。

## 设计判断

旧界面把日期、工具按钮、重点任务、普通任务与表单字段放在相近的视觉层级，默认控件偏小，主要依靠浅灰矩形与绿色文字区分状态。新的设计让日常使用遵循一条明确的路径：看今日概况 → 找到下一步 → 完成或展开 → 继续工作。

- **一个玻璃平面。** macOS 26 使用 `NSGlassEffectView.regular` 承载独立侧栏与导航。内容保持可读的中性表面，不把每个任务再做成一层玻璃。旧系统使用 `NSVisualEffectView`。材质响应系统明暗、透明度与对比度设置。
- **同一套识别。** 开口圆环和一个小圆点代表“下一步”。侧栏、菜单栏和应用图标使用同一形状；图标以银灰底与深青绿构成。保留系统中文字体、SF Symbols 与原生输入组件。
- **克制的色彩。** 钛灰为基础，青绿只表达主要动作、当前进度与焦点任务。普通按钮与内容保持中性色，逾期和错误仍保留明确的语义提示。
- **有主次的阅读。** “今天”作为页面标题，日期作为辅助；右侧圆环使用真实完成/剩余数量。下一步占一个清晰的焦点区域，普通任务使用安静的行与项目分组。
- **小而连贯的反馈。** 页签选择滑动、按钮按下反馈、进度更新使用约 260ms 的弹簧反馈；滚动边缘使用 macOS 26 原生柔化效果。减少动态效果时取消位移/缩放。

## 交互

- 输入区平时收紧，获得焦点或输入文字后展开“今天 / 添加详情”。提交成功清空文字，仅在用户仍在本面板时恢复输入位置；不会为异步返回强行激活 App。
- “全部”增加本地搜索，匹配标题、项目和备注，不创建第二份数据。换页后列表回到顶部，搜索入口稳定可达。
- 详情把“标记完成”固定在底部。编辑与稍后提醒保持近手，提醒提供 10/30/60 分钟，改期、跳过与取消收进更多菜单。
- 新建表单先呈现内容与属性。“时间与重复”按需展开；已有时间的草稿自动展开。主动展开后滚动到该区域。校验错误在对应输入修正后消失，网络/服务错误不会被误清除。
- 设置分为使用习惯、快捷键、提醒通知、数据位置；连接与诊断折叠为次级信息。
- 保留 300–600pt 可变宽度、默认 340pt、宽度记忆、双击复位、草稿保护、离线禁写及非激活面板。菜单栏与刘海快览同步识别与强调色。

## 规范来源与取舍

- [Apple · Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)：导航与内容层分离，使用 Regular，避免玻璃叠玻璃。
- [Apple · Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/)：`NSGlassEffectView` 与 `contentView` 的原生承载方式。
- [Apple · Build a SwiftUI app with the new design](https://developer.apple.com/videos/play/wwdc2025/323/)：胶囊控件、同心圆角、原生滚动/交互层。
- 本地 `redesign-existing-projects`：审视默认模板感、字体层级、空/错/加载态与交互反馈。
- 本地 `ui-ux-pro-max`：运行设计系统与 UX 检索，采用反馈、焦点与减少动态效果建议。搜索结果中的营销页模板、Web 字体和 React Native 实现建议不适合本原生工具，不照搬。
