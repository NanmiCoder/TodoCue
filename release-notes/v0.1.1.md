# TodoCue 0.1.1

轻轻 Cue 你一下，也把灵感一起装进任务里。

- **刘海提醒**：提醒到来时，Cue 标志轻轻跳出来；可直接完成、延后 10 分钟，或打开任务。支持连续提醒排队、自动收起、全屏安静和减少动态效果，不抢走正在输入的键盘焦点。需要带刘海的 Mac，开启刘海快览并保持 App 运行。
- **图文与多附件**：App 可多选图片/文件、粘贴图片；三图横排、四图网格，点击预览，右键另存为。CLI、MCP、API 和 Agent skill 共用附件能力，最多 20 个附件，单个 10 MiB、每任务共 30 MiB。重复任务的附件属于首次实例。
- **可靠保存**：文件内容与任务一起保存在本机数据库，移动原文件后仍可查看。升级前自动备份数据库，附件随数据库备份和 JSON 导出保留；批量上传、删除和文字修改使用同一个事务，支持并发冲突检测与幂等重试。
- **界面修复**：修复白色背景下侧栏圆角外出现灰色矩形边缘的问题。
- **质量门禁**：新增附件、迁移、提醒去重测试，真实 CLI/MCP/HTTP/SSE 冒烟测试，以及每次主分支推送和 PR 的自动检查。发布继续要求两种架构通过测试、签名与 Apple 公证。

安装包提供 Apple Silicon 与 Intel 两种架构，最低 macOS 14。更新后重新打开 App 即可升级内置运行时。任务数据保存在 App 之外，更新会继续读取原数据。
