## 设计判断

- **拼块放在一块托盘里。** 面板由几块独立的圆角块组成，块与块之间留 10pt 空隙，所有块都放在同一块雾面托盘上，托盘每边比块大 14pt，比块之间的空隙略宽，看起来像一圈边框，而不是又一道缝隙；托盘圆角 42，与块的 28 同心。最早是 6pt / 10pt，块几乎贴着托盘边缘，整体显得挤，后来放宽到现在的数值。最初的版本没有托盘，块直接浮在桌面上；放到彩色壁纸上一看，壁纸从空隙里透出来，面板就散成了四块。托盘在 macOS 26 上使用系统的 Liquid Glass（`NSGlassEffectView`），会折射和染上背后壁纸的颜色，边缘带高光，和系统面板的质感一致；macOS 14–15 退回背后模糊加一层浅灰，相当于设计板上那块点阵灰底。一眼要看的内容放在石墨色块上（头部、任务列表、提示条）；要动手处理的放在雾面块上（下一步、表单、设置、日历网格、快速输入）。
- **石墨块永远是深色。** 内部强制深色外观，浅色和深色模式下都一样。雾面块跟随系统外观，并通过 behind-window 模糊透出桌面；开启「减少透明度」时改为不透明底色。
- **宽体数字。** 数字和少量拉丁标签（`TodoCue`、`NEXT`、时间、计数）使用 Michroma（SIL OFL 1.1，打包在 `apps/macos/Resources/Fonts`，启动时注册）。中文和正文仍用系统字体。字体缺失时退回系统字体，不会崩溃。
- **App 图标。** 石墨圆角方块（Apple 1024 网格，主体 824），中间是信号橙的开口圆环和缺口处的提示圆点，与面板左上角的标志同形；外圈 28 个灰色刻度点呼应「下一步」旁的点阵表盘。图标由 `scripts/build-macos.sh` 用矢量逐尺寸绘制：128px 以下不画刻度，64px 以下加粗圆环、放大缺口，避免圆点和圆环粘成一个「O」。
- **一种强调色。** 信号橙 `#F26A2E` 只用于当前选择、主要动作的图标圆盘、进度和提醒。浅色雾面上的小号橙色文字加深为 `#D9541C`，保证可读。逾期改用独立的红色，不和强调色混用。
- **胶囊按钮。** 主要按钮翻转所在表面的颜色：雾面上是石墨胶囊，石墨块上是浅色胶囊，图标放在左侧的橙色圆盘里。次要按钮是描边胶囊，图标按钮是实心圆盘。
- **头部即仪表。** 头部块显示当前视图的大号数字（今日剩余、即将到来、全部待办），三个圆点切换视图。「下一步」块旁边的点阵表盘表示今日进度。列表右侧用宽体显示今天的时间，元信息行就不再重复。

## 动效

所有交互弹簧都来自三个 token（`Dial.snap / settle / pop`），`Theme.interaction` 和 `Theme.bouncy` 只是它们的别名，整个 App 的悬停、按压和弹出用的是同一套节奏。列表增删用临界阻尼弹簧（`Theme.listChange`，0.36 / 1.0），条目合拢时不回弹。开启「减少动态效果」时，一律退化为 0.1–0.15 秒的淡入淡出，不做位移、缩放或循环动画。

| Token | 参数 | 用于 |
| --- | --- | --- |
| `snap` | spring 0.26 / 0.82 | 圆点切换、分段选择、胶囊按压与悬停、输入框聚焦、日历翻页与选日 |
| `settle` | spring 0.42 / 0.84 | 数字滚动、表盘前进、下一步换卡、刘海卡片落定 |
| `pop` | spring 0.34 / 0.58 | 勾选填充、固定按钮旋转、快速添加提交 |

三条原则：

1. **同一时刻只沿一个方向动。** 面板贴着屏幕右边，所以入场时各块从右侧滑入，窗口本身只做淡入。之前窗口横移、各块又纵向上浮，两个方向混在一起。
2. **替换就在原地完成。** 页面、头部、日历的月视图和周视图、列表内容，替换时都叠放在同一个位置，不会上下排开、把高度临时分成两份。新内容用先快后慢的曲线（ease-out）盖上来，旧内容用先慢后快的曲线（ease-in）淡出，两层叠加的不透明度始终接近满格，中间不会出现两层都半透明、桌面透出来的一帧。较深的页面始终叠在较浅的页面上方。
3. **反馈不推动布局。** 提示条浮在页面上方：今日列表和日历页里，放在快速输入框上面；其他页面从头部下方落下，不会盖住「完成」「保存」这些操作。

| 时刻 | 动作 |
| --- | --- |
| 面板从隐藏到出现 | 窗口淡入 0.16s；各块从右侧 18pt 处依次滑入，每块错开 45ms（spring 0.4 / 0.9） |
| 切换今日 / 即将到来 / 全部 | 亮着的橙点滑到新位置；三个标签字重固定不变，不会互相挤动；大号数字滚动到新值；石墨块保持不透明，只有里面的行替换：旧行 0.1s 内淡出，新行从橙点移动的方向滑入 16pt |
| 完成任务 | 圆圈先压到 82%，再弹到 116% 后落定，中心铺满橙色，对勾一笔画出；标题同时划线变淡。这一拍持续 0.42s，之后才真正写入：运行时毫秒级返回，如果立刻写入，SSE 刷新会在对勾画到一半时把这一行拿走。随后该行从左缘缩小淡出，相邻的行临界阻尼地合拢；表盘前进，尖端放出一圈波纹（只在完成一件时出现，加载时不出现） |
| 下一步变化 | 旧任务向上移出，新任务从下方推入，表盘保持不动；整块出现或消失时，从顶部缩放 96% 并淡入淡出 |
| 快速输入 | 聚焦时圆盘变橙，加号旋转 90°；有文字后，加号和向上箭头互换（缩放 40% 并淡入淡出），不会把加号的旋转带到箭头上；提交时圆盘回缩 |
| 进入 / 返回子页面 | 新页面在 0.12s 内淡入（ease-out），同时用弹簧上浮 14pt；旧页面在 0.1s 内淡出（ease-in）。替换表单时，旧表单在下一次按键前就已经消失；头部在原地交替显示仪表和页面标题，高度随之平滑变化 |
| 日历 | 月视图和周视图在原地交替；翻月、翻周时，网格和周列表朝前进方向滑动 24pt；选中日期的橙色圆盘在日期之间滑动；切换日期时，日程列表在原地淡入淡出 |
| 表单 | 日期、重复等弹出框里，开关显示出来的行会缓入，弹出框随之长高；附件区、拖入高亮也有过渡 |
| 加载 | 骨架行以 0.9s 周期呼吸 |
| 刘海展开 / 收起 | 黑色外壳先长出来，卡片晚 0.06s 从 97% 缩放、下移 8pt 落定；收起时卡片先在 0.12s 内离开。行尾的时间和悬停才显示的操作按钮共用一个位置，交叉淡入淡出，标题宽度不会变 |
| 刘海提醒 | 卡片从刘海落下；橙色圆盘先放出两圈错开 0.32s 的波纹，Cue 标记做一次「蓄力—跳起—落地」，然后静止 |
| 悬停 | 列表行浮出浅色底；主要胶囊里的圆盘放大 8%、轻转 −8°；按压时整体缩到 96% |

动效是这样检查的：在离屏面板里驱动真实交互，每 50ms 截一帧排成胶片，逐帧看有没有叠放、闪透和跳动。

## 实现位置

- `DialKit.swift`：token、字体注册、`dialTile`、`DialGauge`、`DialTabDots`、`DialNumeral`、胶囊标签样式、对勾路径、时间标记。
- `PanelRootView.swift` / `ListRootView.swift`：头部块、页面块、列表块与快速输入。
- `SidePanelController.swift`：透明窗口，按托盘圆角裁切。托盘本身由 SwiftUI 的 `DialShell` 绘制。
- `NotchView.swift` / `NotchReminderView.swift`：刘海仍是纯黑，内部换用 Dial 组件和宽体数字。
