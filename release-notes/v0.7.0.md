# TodoCue v0.7.0

v0.6.2 之后的功能版本：刘海可以固定在指定显示器或跟随鼠标换屏，设置界面重做为四个页签，并修复右键 NEXT 卡片时弹出系统 WebView 菜单的问题。任务引擎、REST API、CLI、MCP 和数据库格式没有变化，数据目录与 v0.6.2 兼容。

## 下载与安装

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。将 TodoCue.app 拖入 Applications，退出旧版后打开。两个 DMG 均经 Developer ID 签名、Apple 公证及 stapling 验证。
- Windows：x64 选择 `Windows-x64-setup.exe`（Windows 10/11），ARM64 选择 `Windows-arm64-setup.exe`（Windows 11）。Windows 安装包未做 Authenticode 签名，系统可能显示未知发布者；请只从本仓库 Release 下载，并核对 SHA256SUMS。
- 从 v0.6.2 升级：直接用新安装包覆盖安装，数据保留。

## 本版变化

- **刘海显示器选择**：刘海可固定在指定显示器，或跟随鼠标换屏，并支持顶部、左侧、右侧停靠，解决外接屏幕上无法调整刘海位置的问题。固定的显示器断开时回退到主屏，重连后恢复。
- **刘海更紧凑**：带刘海的 Mac 按摄像头实际尺寸贴顶留空，两翼各 22 点，图标和数字距摄像头边缘 2 点；内建屏收起宽度从 273 缩至 229 点，数量超过 99 显示 `99+`。修正了跨屏缩放时的定位，全屏静默改为按刘海所在屏判断。
- **设置界面重构**：分为通用、刘海、通知、数据四个页签，支持中英文、深色模式、键盘操作与减少动态效果。修复宽度滑杆连续输入时丢失焦点、保存竞争，以及重连失败仍显示成功的问题。
- **右键 NEXT 卡片打开自绘任务菜单**：面板和刘海里的 NEXT 卡片此前右键会弹出 WebView 自带的 Look Up / Translate 菜单（WebKit 右键会自动选中光标下的词，被误判为"有选中文字"）。现在打开与任务行一致的菜单；详情页内选中文字仍可用系统菜单复制。

## 升级、边界与回退

默认数据仍在 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），支持 `--home` / `TODOCUE_HOME`。旧的 SwiftUI 客户端运行时，通用版会提示先退出，避免同时操作同一份数据。

本版仍不提供旧 SwiftUI 客户端的 Apple 日历/提醒事项同步、硬件刘海安全区适配及全部偏好自动导入。依赖这些功能的用户可继续使用 v0.5.3，使用同一数据目录即可恢复旧客户端。

刘海的顶部两翼减少了菜单栏占用，但尚未对其他应用的状态图标自动避让；需要完整让出顶部时可选择侧边停靠。贴顶布局、显示器下拉、滑杆连续键盘输入和失败重连已在内建刘海屏上原生验证；Windows 以及多台物理显示器的组合、NEXT 卡片右键菜单在刘海窗口中的高度（复用任务行菜单的撑高流程）尚未在真机上验收。Windows 的 GUI、多屏/DPI/休眠/通知点击等硬件验收仍保留，详见 [迁移交接](https://github.com/NanmiCoder/TodoCue/blob/main/docs/desktop-handoff.md)。
