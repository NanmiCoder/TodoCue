# TodoCue 0.5.1

按你的节奏，提醒喝水、起来活动和日常小事。

- **独立周期提醒。** 设置每隔几分钟、在哪些星期和时段提醒，支持午休分段。规则持续运行，不生成普通待办，也不进入 TodoCue 日历或 Apple 日历与提醒事项。
- **轻量创建与管理。** 从面板菜单新建，选择活动、喝水或自定义模板，点击间隔、星期和时段即可调整；高级设置默认收起。保存后立即显示下一次提醒，支持撤销创建、编辑、暂停和今天暂停。
- **Agent 一句话创建。** TodoCue Skill、CLI 的 `periodic` 命令组和 MCP 工具共用默认值、校验与摘要；一次调用即可创建完整规则，支持后续修改、完成和延后。
- **两种计时。** 固定模式按时段起点安排；完成后计时模式在确认后开始下一轮，未确认时等待，下个生效日重新开始。支持各规则独立时区，正确处理夏令时边界；休眠和离线期间不补发。
- **静音刘海卡片与系统通知。** 在鼠标所在屏幕展示，支持完成本次、10 分钟后和今天暂停；无法立即展示时使用系统通知。投递确认与用户完成分别记录，重复事件不会再次投递。
- **可靠的状态与保存。** 修复旧缓存提前收起卡片、迟到保存覆盖新输入、时段结束后继续发送、跨日延后和夏令时计算问题，保留现有普通任务与 Apple 同步行为。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App；再次启动时会自动迁移本地数据库，原有任务数据保留在 `~/.todocue`。周期提醒仅在本机运行，不通过 Apple 同步推送到手机。
