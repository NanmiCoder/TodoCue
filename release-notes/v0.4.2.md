# TodoCue 0.4.2

新的 App 图标，与「仪表 Dial」外观统一。

- **新图标。** 石墨色底块上是信号橙的开口圆环和提示圆点，外圈一圈点阵刻度，和面板里的标志、表盘是同一套语言，替换了之前的浅绿色图标。Dock、启动台、访达和通知里都会显示新图标；小尺寸下会简化刻度并加粗圆环，保持清晰。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App 即可；原有任务数据保留在 `~/.todocue`。如果 Dock 或访达仍显示旧图标，重新登录或重启一次即可刷新系统的图标缓存。
