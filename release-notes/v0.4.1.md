# TodoCue 0.4.1

记任务时可以换行了，面板也更透气。

- **输入框支持换行。** 在「记下一件事」和编辑任务中，备注里按 Return 或 Shift+Return 换行，标题里按 Shift+Return 换行；Option+Return 仍然可用。⌘Return 照旧保存任务；用中文输入法打拼音时按回车，仍然是把拼音上屏，不会换行。
- **面板间距更舒展。** 托盘四周的留白从 10pt 加到 14pt，各块之间的空隙从 6pt 加到 10pt，任务列表内侧也留得更宽，内容不再贴着边缘。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App 即可；原有任务数据保留在 `~/.todocue`。
