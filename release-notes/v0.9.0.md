# TodoCue v0.9.0

v0.8.0 之后的功能版本：周期提醒改为按"你上次真正起身"来计时。久坐、喝水、护眼这类提醒不再在你刚站起来一分钟后又响，也不再在你没理会时悄悄沉默。任务引擎、数据库格式没有变化，数据目录与 v0.8.0 兼容；REST API 只新增了字段和一个路由。

## 下载与安装

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。将 TodoCue.app 拖入 Applications，退出旧版后再打开。两个 DMG 均经 Developer ID 签名和 Apple 公证，并已 staple 公证票据。
- Windows：x64 选择 `Windows-x64-setup.exe`（Windows 10/11），ARM64 选择 `Windows-arm64-setup.exe`（Windows 11）。Windows 安装包没有做 Authenticode 签名，系统可能提示"未知发布者"；请只从本仓库的 Release 下载，并核对 SHA256SUMS。
- 从 v0.8.0 升级：直接用新安装包覆盖安装，数据会保留。

## 本版变化

- **新建的周期提醒默认"从上次完成算起"**：你完成后才重新计时。整点、开会这类要对齐钟点的提醒，在创建表单里选"固定时刻"。计时方式从"更多设置"里提到了表单中部，两种方式各带一行实例（例如"09:40 提醒，你 09:47 完成 → 下次 10:27"）。
- **没理会的提醒会再提醒**：新增"没响应时"。默认 10 分钟后同一条提醒再弹一次，最多 3 次，之后留在刘海上等你；可改成 5 / 15 / 30 分钟，或选"不再提醒"。点"10 分钟后"算一次回应，追问次数会重新计。命令行用 `--follow-up <分钟>`，0 表示关闭。
- **离开电脑也算休息（桌面版）**：离开电脑 5 分钟以上再回来，或电脑睡眠过，"从上次完成算起"的提醒会当作你已经起身，待处理的那条自动收掉并重新计时。只读取多久没碰键盘鼠标，不读内容；设置里可以关掉"离开电脑也算休息"。
- **模板带着合适的节奏**：活动（每 40 分钟）、护眼（每 20 分钟）、喝水（每 60 分钟），点一下连间隔和计时方式一起填好。
- **刘海上更清楚**：原来的"已等 2 分钟"改成"已超 2 分钟"，从提醒首次到期算起，超过 10 分钟变暖色；延后过会显示"已推迟 N 次"。追提醒再次落下时，这一行不会消失，并累计 ×N。规则列表里的"等待确认"也改成"已超时 N 分钟"。

## 升级与边界

- **已有规则**：保留各自的计时方式。已经是"完成后重新计时"的规则，升级后也会获得"10 分钟后再提醒"；不想要的话，编辑规则把"没响应时"改为"不再提醒"。固定时刻的规则不受影响。
- **命令行 / MCP / Agent Skill**：不带 `--mode` 创建的规则现在是"从上次完成算起"，不再是固定时刻；需要对齐钟点时请显式传 `--mode fixed`。
- **"离开电脑算休息"是个近似**：只知道你多久没碰键盘鼠标，看文档或开会时也可能被当成起身；不想要就在设置里关闭。
- **尚未在真机上验证**：macOS 上锁屏、睡眠唤醒后空闲时间的读数，以及 Windows 上的空闲时间读取（只做了类型检查）。Windows 版请把这一项当作尚未验证。其余行为已在真实运行时上验证。

默认数据仍在 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），支持 `--home` / `TODOCUE_HOME`。旧的 SwiftUI 客户端仍可用 v0.5.3 回退，指向同一个数据目录即可。
