# TodoCue v0.1.0

TodoCue 是一个本地优先的 macOS 待办工具。人通过菜单栏和浮动面板安排任务，Agent 通过 CLI、MCP 或 Local API 操作同一份数据。

- 今日、即将到来和全部任务视图，支持下一步建议、任务详情、重复任务与提醒。
- macOS 26 原生 Liquid Glass 外观，可调整宽度的浮动面板；旧系统采用兼容材质。
- 快速记录任务、按项目检索、完成与撤销操作。
- App 自带 Node、后台服务、CLI、通知辅助程序及 Agent skill，无需另外安装运行时。
- 数据保存在 `~/.todocue`，替换或重新安装 App 后仍然保留。

## 安装

下载与芯片对应的 DMG：Apple Silicon 选择 `arm64`，Intel 选择 `x64`。打开 DMG，将 TodoCue.app 拖入 Applications 后启动。最低要求 macOS 14；Liquid Glass 外观需要 macOS 26。

需要提醒时，在 App 设置中开启通知权限。版本更新通过下载新 DMG 并替换 App 完成；当前不含 App 内自动更新。
