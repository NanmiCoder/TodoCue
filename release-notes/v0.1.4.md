# TodoCue 0.1.4

拒绝过通知授权的人，终于能重新打开了。

macOS 对同一个 App **一辈子只弹一次**通知授权窗。当初点了「不允许」，之后再点设置里的「请求授权」就永远
没有反应——系统不会再问，也没有任何接口能重置。本次让这个入口在任何状态下都有真实反馈：能弹窗就弹窗，
弹不了就直接把你送到系统设置的通知页面。

- **一键打开系统设置**：授权被拒时，设置里的按钮从「请求授权」变成「打开系统设置」，点一下直达
  「系统设置 › 通知」并定位到 TodoCueNotifier，打开开关即可。此前 App 只写了一句静态文案，没有任何按钮
  能带你过去。
- **状态自动刷新**：从系统设置切回 App 时会自动重新读取授权状态。在此之前需要手动点「重新诊断」，
  否则开关已经打开、界面仍显示「已拒绝」，看起来像没生效。
- **文案说清原因**：授权状态直接写明「macOS 只询问一次，需在系统设置 › 通知中开启 TodoCueNotifier」，
  不再让人误以为是自己没点对。
- **命令行同样可用**：新增 `todocue doctor --open-notification-settings`，在后台运行时也能打开该页面；
  `todocue install` 遇到已拒绝的情况不再静默通过，会明确提示去系统设置开启。

如果你之前从未拒绝过授权，这次更新对你的日常使用没有任何影响。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。下载新 DMG，退出旧版并替换 Applications 中的
TodoCue.app，然后重新打开。原有任务数据继续保存在 App 之外，无需清空数据或重新创建任务。
