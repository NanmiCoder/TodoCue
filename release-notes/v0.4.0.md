# TodoCue 0.4.0

全新「仪表 Dial」外观；合上笔记本、只用外接显示器时，也能用刘海快览。

- **新的面板外观。** 面板由深色和浅色几块拼成，放在同一块托盘里：一眼要看的内容放在深色块上，要动手处理的放在浅色块上。macOS 26 上，托盘使用系统的 Liquid Glass 材质，会透出并折射背后的桌面。数字使用宽体字，强调色统一为信号橙。
- **头部就是仪表。** 大号数字直接显示今日剩余、即将到来或全部待办的数量，三个圆点切换视图。「下一步」旁边加了点阵表盘，显示今天完成了多少。列表右侧用宽体字显示今天的时间，下面那行不再重复。
- **更顺手的动效。** 勾选任务时圆圈会弹一下，对勾一笔画出，任务停留片刻再离开，下面的条目平稳补上。页面、视图和日历切换都在原位置完成，不会闪出背景；切换视图时，列表顺着圆点移动的方向滑入。撤销提示浮在页面上方，不再把列表往上顶。打开面板时各块依次从右侧滑入；提醒从刘海落下时会扩散一圈波纹。开启「减少动态效果」后，以上动画都改为简单的淡入淡出。
- **外接显示器也有刘海。** 合上笔记本或使用没有刘海的显示器时，TodoCue 会在菜单栏中间画一个刘海，跟着鼠标出现在你正在用的那块屏幕上。悬停展开今日任务、点一下固定输入、提醒从这里落下，和真刘海一样。不需要可以在设置 › 刘海快览中关闭「没有刘海的显示器也显示」。
- **Apple 同步的设置更清楚。** 设置里推荐只开「同步到提醒事项」：iOS 18 / macOS 15 起，带日期的提醒也会显示在日历里，两个都开会在日历中重复显示。同时开启时有提示；Mac 未开启 iCloud 日历或提醒事项时，会直接说明去哪里打开。本机的「TodoCue」日历被系统迁移到 iCloud 后，同步会跟随新账户，之后重建也会建在 iCloud 里。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App 即可；原有任务数据保留在 `~/.todocue`。
