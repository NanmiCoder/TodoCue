# TodoCue 0.1.2

和 Agent 聊到的事，一句话变成待办。

TodoCue 通过 Skills，让支持本机命令的 Agent 用自然语言创建、查询、改期和完成任务，也能设置提醒。任务同步显示在 Mac 面板中；原有表单和快速添加入口继续保留。本次重写 README，补充从 Agent 对话到本机待办的使用场景与接入说明。

- **中英文界面**：设置中可切换 English 与简体中文，立即生效并保存选择。列表、表单、菜单栏、刘海快览、提示和日期显示跟随语言，任务内容保持原文。首次启动跟随系统语言，其他语言回退到英文。README 默认英文，并提供完整中文版本。
- **拖拽联动**：拖动卡片跟随鼠标，相邻任务和组头平滑让位，松手落位，取消归位。支持边缘滚动与减少动态效果。
- **按分组安排**：「全部」支持跨项目移动，「即将到来」支持跨日期改期，「今日」仅在同组内排序。顺序按视图和分组保存，可撤销或恢复自动排序，不改变任务的重要性标记。
- **改期有边界**：跨日期保留时区和计划时间，截止日期与提醒保持原值；计划晚于截止时间时先确认。重复任务只移动当前实例。
- **可靠保存**：移动和排序在同一事务内提交，版本冲突时不覆盖其他修改。升级前自动备份数据库，新增排序表，不重写既有任务、系列、提醒或附件。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。下载新 DMG，退出旧版并替换 Applications 中的 TodoCue.app，然后重新打开。原有任务数据继续保存在 App 之外，无需清空数据或重新创建任务。
