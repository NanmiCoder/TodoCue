# TodoCue v0.10.1

v0.10.0 之后的刘海提醒修复版本。任务引擎、REST API 和数据库格式没有变化，原有任务、附件与设置保持兼容。

## 本版变化

- 修复刘海里的周期提醒卡片（如“不要久坐起来”）每次都带着同一行红字“本次投递已由其他通道处理”。提醒触发后 3 秒内刘海没认领到、改由系统通知送达时，刘海随后的认领会被运行时拒绝；这是正常结果，现在不再显示为错误。
- 刘海上的错误提示 6 秒后自动消失，不再停留到后面的提醒卡片上。断网等真实故障仍会提示。

## 下载与升级

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。退出旧版，将 TodoCue.app 替换到 Applications 后重新打开。正式 Mac 包通过 Developer ID 签名及 Apple 公证。
- Windows：Windows 10/11 x64 选择 `Windows-x64-setup.exe`；Windows 11 ARM64 选择 `Windows-arm64-setup.exe`。Windows 安装包未做 Authenticode 签名，请从本仓库 Release 下载并核对 `SHA256SUMS`。
- 覆盖安装保留数据。默认目录仍为 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），也可继续使用原有 `TODOCUE_HOME`。

## 验证与边界

在隔离运行时和浏览器预览的真实刘海组件上，把认领请求延迟到 3.6 秒来模拟认领变慢：修复前，下一次提醒的新卡片会带着上一次留下的错误；修复后认领被拒时不显示错误，正常认领无错误，模拟的网络故障仍会提示并在约 6 秒后消失。桌面端构建与测试通过。

没有在真机刘海窗口和 Tauri 通道上验证。刘海有时 3 秒内认领不到、改由系统通知送达的原因尚未查明，本版不改变这一点，只是不再把它显示成错误。
