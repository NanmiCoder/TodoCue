# TodoCue 0.3.0

把任务带到 iPhone 上：双向同步到 Apple 日历与提醒事项。

不用另装 iOS App。打开同步后，TodoCue 的任务会出现在 iCloud 里的「TodoCue」日历和提醒事项列表中，iPhone、iPad 上的系统 App 直接就能看、能改。

- **两个独立开关。** 在设置 › Apple 日历与提醒事项中分别开启「同步到日历」「同步到提醒事项」，默认关闭。首次开启时 macOS 会请求访问权限；被拒绝时提供「打开系统设置」入口。
- **有日期的待办自动出现。** 有精确时间的任务成为定时日程，时长取预估耗时（默认 30 分钟）；只有日期的成为全天日程。提醒事项以截止时间为准，并带上优先级。完成的任务会从日历移除、在提醒事项中勾选完成。
- **在手机上改，TodoCue 跟着变。** 改标题、备注、日期、时长、优先级，勾选或取消勾选提醒，都会写回 TodoCue；在「TodoCue」日历或列表里新建的条目会成为新任务；删除条目会取消对应任务（可在已完成中重新打开）。
- **两边都改也不丢。** 按字段合并：手机上勾选完成、Mac 上同时改了截止日期，两边的修改都会保留；只有同一项被两边同时修改时，才以 TodoCue 为准。
- **不会误删任务。** 条目需持续消失 10 分钟以上才会取消任务；一次性大批消失（如 iCloud 重新同步）时暂停取消并提示。条目被移到别的日历或改成重复事项时，只会停止同步，任务保持原样。iCloud 暂时不可用时暂停同步，不会悄悄换到别的账户。
- **不额外打扰。** TodoCue 不给同步过去的日程和提醒设闹钟，提醒仍由 Mac 上的 TodoCue 发出。「移除同步数据」会删除 Apple 侧的「TodoCue」日历或列表，TodoCue 里的任务不受影响。

同步在 TodoCue.app 运行时进行；请只在一台 Mac 上开启。详细规则见 [Apple 日历与提醒事项同步](https://github.com/NanmiCoder/TodoCue/blob/main/docs/apple-sync.md)。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App 即可；原有任务数据保留在 `~/.todocue`。
