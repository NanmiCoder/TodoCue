# TodoCue 0.2.0

美学大换血：告别繁重表单，让记录重归轻盈与愉悦。

待办事项不该像在填报税表。本次对 TodoCue 的视觉美学与核心交互进行了全方位大重构，带来全新的 **Nordic Glass & Canvas** 原生设计语言：一体式灵动画布、触手可及的属性胶囊栏、去噪后的纯净列表与每一次勾选带来的多巴胺正反馈。

- **渐进式灵动任务面板 (Fluid Task Composer)**：彻底推翻原本 4 块生硬割裂的白色大方块卡片。现在是一整块如优质纸张般的沉浸式书写画布，大字重标题随心换行、备注自然铺展。计划日期、项目、优先级、预估耗时、重复与附件等所有配置，统一收拢为输入框下方轻巧的交互药丸（Attribute Chips）。
- **呼之即来的日期与属性配置**：点击日期胶囊原地呼出微型日历浮窗，内置「今天 / 明天 / 清除」快捷预设、图形日历、截止时间与提醒；项目胶囊支持即时检索、点选已有项目与一键清除；优先级一键切换珊瑚红、琥珀金与冷雾蓝标识。
- **智能附件抽屉与直接拖拽**：日常记事不再被庞大的附件上传区域打断。无附件时完全隐形，零空间占用；添加附件后以精巧网格展示，并支持将文件或图片直接拖拽丢入窗口导入。
- **列表视觉降噪 (Ghost Drag Handles)**：原本常驻在每行左侧的 6 点拖拽图标全面改为悬浮隐现。日常浏览时完全隐形，文字对齐干净利落；仅在鼠标悬停或拖拽时柔和浮现。
- **多巴胺弹性复选框**：重新调校复选框物理动效。悬停时泛起微光，勾选完成时触发 Spring 物理弹性回弹，配合丝滑划线与柔和渐隐，让每一次完成都极富仪式感。
- **呼吸光晕「下一步」卡片**：告别原本厚重的实体色块，升级为微渐变半透背景、双层薄荷青呼吸指示灯与细腻发光描边。
- **Nordic Mint 全新色彩体系**：重新校准高质感北欧薄荷青（浅色温润碧翠、暗色通透发光），搭配双层微光描边与环境软阴影，彻底摆脱原本沉闷发灰的底色。

原有任务数据、快捷键、API 与本地服务 100% 完美保持，无需清空数据或重新配置。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。下载新 DMG，退出旧版并替换 Applications 中的 TodoCue.app 即可。
