# TodoCue v0.10.0

v0.9.2 之后的功能版本：macOS 上，其他日历里新建的日程可以自动成为 TodoCue 任务。以前只有「TodoCue」日历里的日程会进 TodoCue，所以别的 App 写进日历的面试、预约（比如「BOSS直聘日历」）一直进不来。任务引擎、REST API 和数据库格式没有变化，原有任务、附件与设置保持兼容。

## 本版变化

- **从其他日历导入（macOS）**：设置 › 同步 里新增第三个开关，默认关闭。打开后，这台 Mac 上其他日历里还没结束的一次性日程会成为任务：标题、备注照搬，时间写入计划时间，时长写入预计耗时。以后新出现的日历（比如某个 App 新建的）也自动包含；设置里列出全部日历，可以逐个取消勾选。订阅日历、生日、Siri 建议之类的系统日历不导入，重复日程也不导入。
- **单向、只读**：TodoCue 不会修改、完成或删除那些日历里的日程，导入的任务也不会再复制进「TodoCue」日历，同一个日程不会在日历里出现两次。
- **那边改了，任务跟着改**：日程改时间、改标题、改备注，任务按字段跟随；你在 TodoCue 里改过的字段以 TodoCue 为准。
- **那边删了，任务标为已取消**：日程连续 10 分钟以上找不到时，任务标为已取消（不删除，可以重新打开）；日程如果又出现了，任务自动重新打开。一次消失太多时会暂停处理并在设置里提示。
- **不会重复导入**：在 TodoCue 里完成或删除的导入任务不会再回来；撤销完成后，任务重新跟随原日程。

## 下载与升级

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。退出旧版，将 TodoCue.app 替换到 Applications 后重新打开。正式 Mac 包通过 Developer ID 签名及 Apple 公证。
- Windows：Windows 10/11 x64 选择 `Windows-x64-setup.exe`；Windows 11 ARM64 选择 `Windows-arm64-setup.exe`。Windows 安装包未做 Authenticode 签名，请从本仓库 Release 下载并核对 `SHA256SUMS`。本版的新功能只在 macOS 上提供。
- 覆盖安装保留数据。默认目录仍为 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），也可继续使用原有 `TODOCUE_HOME`。

## 验证与边界

在真实的 Mac 日历上验证了日历筛选（「TodoCue」、生日、Found in Mail、Scheduled Reminders 均被排除）、导入内容（标题、时间、带链接的备注），以及排除再勾选不会重复导入。改期跟随、删除后取消、日程回来后恢复，以及独立审查发现并修复的 5 个问题，由单元测试覆盖，没有为此改动真实日历。打开导入时，macOS 可能请求日历的完整访问权限。

- 导入只在 TodoCue 运行时进行，日程结束后不再导入。部分 App 写入的日程时长只有几秒（如 BOSS 直聘），开始时间一过就算结束。
- 地点、参会人和日程自带的闹钟不导入。
- 回退到 v0.5.3 期间不导入；如果那时开着「同步到日历」，导入的任务会被复制进「TodoCue」日历。

设计与规则见 [Apple 同步 › 从其他日历导入](../docs/apple-sync.md#从其他日历导入)，检查范围见[验收记录](../docs/qa/calendar-import/README.md)。
