# TodoCue v0.10.2

v0.10.1 之后的修复版本。任务引擎、REST API 和数据库格式没有变化，原有任务、附件与设置保持兼容。

## 本版变化

- 修复刘海里的周期提醒（如“不要久坐起来”）有时弹一下就消失。刘海认领提醒后，面板数据要稍后才刷新，期间每秒一次的同步用触发前的旧数据判断，把刚弹出的卡片当成已结束删掉；现在会等新数据到了再判断。刘海窗口尺寸动画被下一次尺寸调整接替时，也不再误判为“没显示出来”。
- 面板里点“添加到今天…”旁的详情按钮或按 ⌘N（Windows 为 Ctrl+N）新建任务，默认安排在今天（日历视图里为选中的那天），保存后不再落进“未分组”。需要时仍可在日期标签上清除日期。

## 下载与升级

- macOS 14+：Apple Silicon 选择 `macOS-arm64.dmg`，Intel 选择 `macOS-x64.dmg`。退出旧版，将 TodoCue.app 替换到 Applications 后重新打开。正式 Mac 包通过 Developer ID 签名及 Apple 公证。
- Windows：Windows 10/11 x64 选择 `Windows-x64-setup.exe`；Windows 11 ARM64 选择 `Windows-arm64-setup.exe`。Windows 安装包未做 Authenticode 签名，请从本仓库 Release 下载并核对 `SHA256SUMS`。
- 覆盖安装保留数据。默认目录仍为 `~/.todocue`（Windows 为 `%USERPROFILE%\.todocue`），也可继续使用原有 `TODOCUE_HOME`。

## 验证与边界

周期提醒：本机历史记录里约一到两成的周期提醒以“App could not display the claimed cue”失败；新增的回归测试在修复前失败、修复后通过。没有在真机刘海窗口上复测，需安装后观察是否还出现这类失败。

新建任务：在隔离运行时和浏览器预览里，修复前从详情按钮打开的表单没有日期、保存后进入“未分组”；修复后表单显示“今天”，保存后任务出现在“今日 · 已安排”。没有在安装后的 App 里复测。
