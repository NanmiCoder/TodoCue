# TodoCue v0.1：本地 Task Runtime 与 macOS 桌面体验

## 1. 目标与交付范围

实现一个可在你的 Mac 上日常使用的任务系统：人通过精致、紧凑的 macOS UI 管理任务，Agent 通过 CLI、MCP 和 Local API 操作同一份数据。

首版包含：

- 独立的 TypeScript / Node.js Task Runtime。
- SwiftUI + AppKit macOS 客户端，提供刘海快览和右侧悬浮面板。
- 单次任务、每日／每周重复任务、系统提醒。
- 图形界面的添加、编辑、完成、改期及重复任务设置。
- CLI、MCP、Local API，以及本机安装、后台运行和诊断能力。

自然语言仍由调用方 Agent 理解；桌面端使用紧凑表单和日期选择器。首版不加入内置 AI 聊天、日历联动、自动排程、云同步和公开分发安装包。

完整计划最终保存到项目内的 `docs/implementation-plan.md`。

## 2. macOS UI 与交互设计

### 刘海快览

将刘海作为任务的快捷入口，在摄像头缺口周围和下方绘制界面，所有文字与按钮避开物理遮挡区域。

| 状态 | 呈现与交互 |
|---|---|
| 收起 | 黑色轮廓与刘海融合，两侧各 44pt 小翼常显 Cue 标记与今日剩余数（清空后收回，可在设置中关闭）；整条黑条都是悬停热区 |
| 悬停展开 | 停留 200ms 后向下展开，宽 560pt、高度随内容变化，上限 560pt；高度由内容实际测量得出，不依赖窗口反推 |
| 快览内容 | 今日日期与进度、下一步（含倒计时或截止提示）、逾期／必须完成／已安排最多 5 条；每条可完成、10 分钟后提醒、改期到明天、打开详情；底部快速添加，回车即加入今天 |
| 固定与输入 | 点一下刘海即展开并固定，面板成为键盘焦点但不激活 App，光标落在输入框；输入时同样固定；头部图钉可切换 |
| 深入处理 | 点击任务正文，在右侧面板打开该任务；“查看全部”与“+”打开面板；操作反馈从刘海下方滑出，不遮挡列表和输入框 |
| 收起 | 非固定时离开热区及展开面板 350ms 后收起；Esc 先清空草稿再收起；点击面板外、切换桌面空间或打开侧栏立即收起，键盘焦点交还原来的 App |

快览使用 Runtime 返回的任务排序，不维护另一套优先级规则。打开右侧面板后收起快览，避免同时展开两份任务列表。

### 右侧悬浮面板

- 手动打开或再次打开 App 时，在当前鼠标所在显示器的右侧呈现面板。
- 默认宽 **380pt**、高 **680pt**，距可用桌面边缘 **12pt**；小屏幕下限制在可用区域内，内容内部滚动。
- 默认点击外部或按 `Esc` 收起；提供“固定”按钮，固定后点击外部仍保持显示。
- 编辑时支持正常键盘输入；关闭表单、面板采用逐层返回方式，有未保存内容时保留草稿。
- 关闭面板后 App 常驻菜单栏，后台任务与提醒继续运行；登录自启动只进入常驻状态。

面板采用单列布局：

1. **顶部**：今日日期、剩余任务数、固定按钮和更多操作。
2. **下一项**：突出一条当前最值得处理的任务，展示时间、项目和预计耗时。
3. **任务列表**：通过“今日 / 即将到来 / 全部”切换，今日任务区分逾期、必须完成和已安排。
4. **底部**：快速添加入口，以及可折叠的今日完成记录。

添加和编辑表单在面板内部展开，包含标题、备注、项目、优先级、预计耗时、计划时间、截止时间、提醒和重复设置。任务详情替换面板内容，不额外打开大窗口。

完成任务后提供短暂的撤销入口；撤销恢复任务状态，不补发已经过去的提醒。

### 视觉与动效

- **整体风格**：原生通透感。刘海区域保持黑色，侧栏跟随系统浅色／深色，采用磨砂材质、细边缘和柔和阴影。
- **信息层级**：使用系统字体和 SF Symbols，任务标题约 14pt，辅助信息约 12pt；标题最多展示两行，详情中完整显示。
- **布局**：面板圆角约 22pt，主要内容留白 16–20pt。通过分组和间距建立层级，避免每条任务都套厚重卡片。
- **强调色**：使用少量薄荷绿突出主要动作与完成状态；浅色模式使用更深的对应色保证对比度。逾期同时使用文字或图标说明。
- **动画**：展开约 260ms，收起约 180ms；使用克制的弹性和轻微位移。完成任务时勾选、淡出并平滑收拢列表。
- **辅助功能**：支持 VoiceOver、键盘操作、系统“减少动态效果”和“降低透明度”；减少动态效果时改用短淡入淡出。

### 显示器与系统行为

- 根据各显示器实际几何和安全区域定位，不硬编码某款 MacBook 的刘海尺寸。[Apple 屏幕安全区域](https://developer.apple.com/documentation/appkit/nsscreen/safeareainsets)
- 有刘海的内建屏提供刘海入口；无刘海屏通过菜单栏打开同一任务面板。
- 显示器插拔、缩放及桌面空间切换后重新计算位置，保证面板留在可见区域。
- 全屏应用中默认关闭刘海悬停自动展开；支持显式唤出面板。
- 提供可配置的全局快捷键，默认不绑定，避免占用用户现有快捷键。
- 提醒到达时更新数量和任务状态，通过系统通知提示，不强制展开侧栏或抢占输入焦点。

## 3. 架构与公共接口

整体数据流为：

**macOS UI / CLI / MCP → Local API → Task Engine → SQLite**

- **Runtime**：TypeScript、ESM、npm workspaces、Fastify、Zod、Vitest；以 Node 24 LTS 为基线，同时验证本机 Node 26。[Node 发布状态](https://nodejs.org/en/about/previous-releases)
- **Task Engine**：独立实现任务规则、查询排序、重复实例及状态变更，通过接口依赖存储、时钟和通知能力。
- **后台服务**：单实例 Node 服务承载 Engine、API 和调度器，是数据库的唯一业务写入入口。
- **存储**：SQLite、better-sqlite3、WAL。数据默认保存在 `~/.todocue`，支持 `TODOCUE_HOME`；任务变更与提醒记录在同一事务中提交。
- **macOS 客户端**：SwiftUI 负责界面和动画，AppKit 负责窗口、菜单栏、屏幕定位及鼠标跟踪。刘海快览使用非激活面板，悬停查看不激活 TodoCue。[非激活面板](https://developer.apple.com/documentation/appkit/nswindow/stylemask-swift.struct/nonactivatingpanel)
- **通知组件**：保留独立 Swift 通知辅助程序，随本机安装一起部署；不依赖任务窗口是否打开。通知点击后定位到右侧面板中的对应任务。
- **MCP**：使用官方 TypeScript SDK v2，提供 `todocue mcp` stdio 入口，各 Agent 共享后台 Runtime。[MCP SDK](https://ts.sdk.modelcontextprotocol.io/v2/)

Local API 仅监听 `127.0.0.1`，采用本地随机令牌认证；客户端读取仅当前用户可访问的连接配置。

公共接口包含：

| 类别 | 能力 |
|---|---|
| 任务 | 创建、查询、修改、完成、重新打开、取消、跳过、稍后提醒 |
| 系列 | 创建、查询、停止每日／每周重复系列 |
| 查询 | `today`、`next`、任务筛选及当前时间／时区上下文 |
| 提醒 | 查询待发送、已提交、失败和错过的提醒 |
| 运维 | 安装、服务启停与状态、诊断、JSON 导出 |
| 实时更新 | 新增 `/v1/events` SSE 接口，通知任务、系列和提醒变化 |

三种程序接口共用参数定义、返回类型和错误码；CLI 业务命令支持 `--json`。

桌面端先订阅事件，再读取快照；收到事件后刷新受影响的数据，重连后重新同步。连接中断时显示上次数据及离线状态，暂停写入，避免产生未经提交的任务变更。

## 4. 任务、时间与可靠性规则

- **任务模型**：包括标题、备注、项目、优先级、预计耗时，以及相互独立的计划时间、截止时间和提醒时间。状态为待办、完成、取消、跳过；跳过仅用于重复实例。
- **一致性**：任务带版本号，修改进行版本检查；旧版本请求返回冲突，客户端刷新后提示。写入支持幂等键，避免重试产生重复任务。
- **时间**：日期级计划和截止日期保留日期精度；提醒必须指定具体时刻。具体时刻以 UTC 保存，同时保留 IANA 时区。首次设置读取并持久化系统时区。
- **今日查询**：返回今日计划、今日截止，以及此前遗留的计划和逾期任务，标明入选原因；今日完成记录按实际完成日期展示。
- **下一项查询**：排除尚未到计划时间的任务，按逾期截止、今日截止、已到计划时间、未安排任务分组，再按优先级、截止时间和创建顺序排序，并返回原因。
- **重复任务**：采用系列与独立实例；每日或每周指定星期生成，预生成未来 30 天，在启动、跨日和查询时补齐。昨天未完成不影响今天生成。
- **系列操作**：新建时可设置重复；编辑、改期、完成和跳过仅影响当前实例。停止系列取消尚未开始的实例并保留历史；首版修改重复规则通过停止旧系列、新建系列完成。
- **夏令时**：重复任务保持系列时区的本地时间；不存在的时刻顺延到有效时间，重复时刻取第一次。
- **提醒**：每个实例支持一个显式提醒；稍后提醒只修改提醒时间。完成、取消、跳过会使未发送提醒失效。
- **恢复**：提醒持久化，发送前检查最新任务状态；失败可重试，并复用稳定提醒标识减少重复。正常唤醒运行时，到点后 10 秒内提交系统；启动或睡眠恢复后补查错过提醒，多条合并为摘要。
- **授权**：通知未授权时任务功能继续可用，设置页和 `doctor` 显示具体状态；“已提交系统”不代表用户已读。

## 5. 实施顺序与验收

### 实施顺序

1. **原生交互验证**：先做刘海展开、侧栏、焦点切换和通知的最小原型，验证真实 Mac 上的定位、透明材质与窗口行为。
2. **任务核心**：完成数据库迁移、Task Engine、Local API、CLI，以及并发和幂等处理。
3. **桌面界面**：完成统一视觉样式、快览、任务列表、编辑表单与状态反馈，接入真实 API 和实时更新。
4. **时间与后台**：完成重复实例、持久化提醒、通知点击定位、LaunchAgent 和安装诊断。
5. **Agent 与自用闭环**：完成 MCP、接入说明、导出及完整使用验证，整理 Markdown 计划和运行文档。

### 验收场景

- **跨入口一致性**：Agent 创建任务后，刘海和侧栏在正常本地连接下 1 秒内反映变化；UI 完成任务后，CLI 和 MCP 查询结果一致。
- **交互正确性**：鼠标快速路过不会展开；悬停进入列表不闪退；快览不抢焦点；侧栏可编辑、收起和固定；手动启动 App 能看到任务。
- **视觉质量**：检查深浅色、不同壁纸、中文长标题、大量任务、空列表、加载、离线和错误状态；留存真实桌面截图及展开／收起录屏。
- **系统兼容性**：检查刘海屏、无刘海屏、多显示器、缩放、全屏、桌面空间切换、减少动态效果和键盘访问。
- **业务可靠性**：覆盖重复提交、并发修改、昨日未完成、单次改期、跳过、停止系列、跨日、夏令时和撤销完成。
- **后台可靠性**：关闭面板和终端后仍能提醒；重启、重新登录、休眠恢复、拒绝通知权限及辅助程序失败均有正确行为和诊断信息。
- **数据保护**：测试使用可控时钟与临时数据库；迁移记录版本并提前生成一致性备份；卸载服务保留任务数据。

默认面向单用户、单设备，macOS 客户端最低目标为 macOS 14。所有项目共享个人任务库，Runtime 负责管理任务与提醒，不自动执行任务正文中的命令。
