# Todo 列表拖动

## 行为

拖动任务左侧六点手柄调整执行顺序，不改高／中／低／无的重要性标记。排序按视图和分组独立持久化。

| 视图 | 同组 | 跨组 |
| --- | --- | --- |
| 全部 | 项目内手动排序 | 修改项目，并插到目标位置；“未分组”清空项目 |
| 今日 | 逾期、必须完成、已安排各自排序 | 禁用，提示分组由截止日期决定，应编辑日期 |
| 即将到来 | 同一天内排序 | 修改计划日期，并插到目标位置 |

- 分组顺序不变。未手动排序的组沿用自动排序；已手动排序的组，新任务追加在已有顺序后。
- 手动排序组的标题右侧提供“恢复自动排序”；可撤销。
- 今日排序按当天分组保存，次日使用当天的新分组，不继承昨日排序。
- “下一步”卡片的任务保留在今日列表，允许调整相对位置。推荐按今日分组和手动顺序，排除尚未到计划时间的任务，再回退到未安排任务。
- 即将到来按任务时区中的计划日期分组，没有计划才回退到截止日期。今日独立显示逾期和今日截止事项，因此任务可以同时出现在两个视图。
- 跨日期保留计划的时分秒与时区，保留全天／具体时间精度。没有计划的任务新增全天计划。截止时间和独立提醒不改；超过截止时间须明确确认。夏令时缺失时间沿用运行时的时间解析规则。
- 重复任务只修改当前实例，保留 `seriesId` 和 `occurrenceDate`，不改重复规则或其他实例。
- 搜索结果禁用拖动，清除搜索后恢复。已完成、离线、保存中或等待改期确认时不能拖动。
- 支持组首、组尾和空“未分组”落点。首版在当前视图的可见分组间移动，不通过拖拽新建项目、日期分组或切换标签页，不支持多选拖动。

## 原生交互

面板内使用 AppKit 鼠标追踪，不导出任务到系统剪贴板。行和组头／组尾以原生视图注册落点；命中必须同时位于自身 bounds、可见区域和滚动区域内。鼠标在行上半部插入该行之前，下半部插入之后。

手柄移动超过 6 点后开始拖动。任务卡片轻微抬起并直接跟随鼠标，经过的任务以 200 毫秒缓动让位，目标位置显示真实空位；跨组时组头和组尾也参与让位。落点使用未变换的原始布局测量，行间小间隙保持连续命中，避免动画反过来改变命中结果而产生跳动。

拖动期间冻结服务端刷新产生的列表布局，仅投影显示顺序，不修改任务数据。提示和保存状态覆盖在滚动区域底部，不改变落点位置。靠近滚动区域边缘时持续滚动。松手才发送请求；Esc、窗口关闭、无效落点和拖出面板均不提交，并平滑归位。系统开启“减少动态效果”时缩短过渡并取消放大。

松手后用 220 毫秒过渡落入目标位置，保存期间保留预览。服务端快照就绪且落位完成后，一次性切换真实列表与清除预览，避免先弹回再重排。保存成功提供 10 秒撤销入口；失败或需要截止日期确认时，先归位再显示提示，不做需要额外回滚的乐观字段写入。

## 数据和接口

- v3 迁移只新增 `list_ordering` 表和任务写入触发器，不重写现有任务、系列、提醒或附件。沿用 `VACUUM INTO` 迁移前一致性备份；迁移在事务内执行。
- `GET /v1/board` 同时返回 context、today、next、all、upcoming 和排序 revision，原生客户端避免混用不同请求的列表和版本。
- `POST /v1/tasks/:id/move` 接收 view、sourceGroup、targetGroup、beforeId、expectedVersion、expectedRevision 和可选 allowPastDeadline。
- `POST /v1/ordering/reset` 恢复一个分组的自动排序。
- `POST /v1/ordering/undo` 使用服务端保存的撤销 token 和操作后的 revision 恢复字段及顺序。
- 移动字段、排序和撤销凭据在同一事务中写入，提交后才发出事件。目标消失或请求冲突时全部回滚。
- 全列表 revision 在任务新增、修改、删除或排序操作后增加。采用保守冲突策略：任何后续任务写入都使旧移动请求及撤销凭据失效，避免覆盖并发修改。提醒投递状态变更不会使排序撤销失效。
- 只保留最后一次排序操作的撤销凭据；该凭据可跨运行时重启保存，但 UI 撤销入口仍限于当前提示。
- 导出 JSON 附带可选 ordering 字段，旧导出格式仍可解码。

## 验证与数据隔离

测试和原生预览使用临时 TODOCUE_HOME、测试任务、临时端口以及 MemoryNotifier，不连接用户运行时，不替换已安装应用。

自动测试覆盖组内任意排序、视图独立性、跨项目／日期、重复实例、任务时区与 DST、截止确认、原子回滚、并发冲突、今日推荐、日期切换、旧库保留及备份、重启持久化、API 鉴权和幂等、原生落点边界、搜索／离线相关状态、Esc 取消与边缘滚动。

动效测试额外覆盖可变行高、上下移动、跨组空位、反向拖动、滚动时抓取点稳定、行间隙命中，以及真实 SwiftUI 视图让位时原生测量坐标保持不变。原生组件帧截图使用合成测试任务生成。

隔离原生预览验证了组内精确插入、跨日期确认与撤销、跨项目移至未分组与撤销，以及搜索禁用提示。
