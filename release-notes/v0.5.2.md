# TodoCue 0.5.2

现在可以直接删除待办，并与 Apple 日历和提醒事项双向同步。

- **永久删除待办。** 右键任务行，或在详情页的 `⋯` 菜单里选择「删除」，确认后连同提醒和附件一起删除，无法撤销。已完成、已取消的任务也可以删除；重复任务只删除这一次，后面的安排不受影响。只想从列表里拿掉、又想保留记录时，仍然用「取消」。
- **命令行与 Agent 同样可用。** `todocue delete`（别名 `rm`）和 MCP 工具 `todocue_delete_task`。TodoCue Skill 要求 Agent 只在你明确说要删除时才使用。
- **Apple 同步双向删除。** 在 TodoCue 删除任务，日历事件和提醒事项会随之清除；在 iPhone 或 Apple 日历、提醒事项里删除条目，约 10 分钟后 TodoCue 里对应的任务也会被永久删除（此前只是取消）。已完成的任务在那边被删，只解除关联；一次有很多条目同时消失时会暂停删除并在设置里提示，避免同步异常时误删。
- **提醒与同步更稳。** 修复在提醒发出的瞬间删除任务，可能让后台服务退出并重启的问题；Apple 条目短暂消失后重新出现，不再提前用掉 10 分钟的等待；后台服务版本较旧、没有删除接口时，不再误报“已删除”。
- **更早的任务也能打开详情。** 从「已完成」列表或日历里点开早于今天完成或取消的任务，现在能看到详情，并重新打开或删除。

提供 Apple Silicon 与 Intel 安装包，最低 macOS 14。退出旧版后，用新 DMG 中的 TodoCue.app 替换 Applications 中的旧 App。本版本不改变数据库结构，原有任务数据保留在 `~/.todocue`。
